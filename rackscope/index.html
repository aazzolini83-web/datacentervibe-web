Keep practical prompts close at hand without turning the landing into documentation. Open a use case, copy the prompt, and adapt the MVP.

PROMPT 01Map my existing ExcelConvert legacy inventory into RackScope format
Attached are two Excel files: File A (my legacy data center inventory) and File B (RackScope target format with columns: Rack_ID, U_Pos, Height, Device, Type, Power_kW). Write a Python script using pandas to map and populate File A into File B format automatically without losing device positions.
PROMPT 02Generate lifecycle reportsCompare monthly inventory changes
Write a script or function that compares this month's Excel inventory with last month's inventory to generate a report showing total Rack Units decommissioned, newly activated, and net capacity change per room.
PROMPT 03Add an MMR moduleExtend fiber and cross-connect visibility
Modify this HTML interface to add a Meet-Me Room view with dedicated fiber patch-panel racks, fiber interconnect mapping, and a dashboard displaying port density and cross-connect availability.
PROMPT 04Move the dataset onlineEvolve Excel into a cloud data layer
I want to convert this Excel sheet into an online cloud database. Show me how to migrate the data to Supabase (PostgreSQL) or Firebase, provide the database schema, and explain suitable hosting options for API access.
