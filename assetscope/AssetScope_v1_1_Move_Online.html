Import the workbook and run the readiness check.

// PURPOSE

AssetScope manages non-IT Data Center infrastructure such as chillers, switchboards, UPS systems, PDUs, mPDUs, CRACs, InRows, Rittal cooling systems and generators.

// ASSET INVENTORY

Import the master workbook or add equipment from the interface. Store category, type, manufacturer, model, serial, management IP, purchase date, end of support, end of life, owner, status and criticality.

// MAINTENANCE

Register preventive and corrective interventions. Each record references Asset_ID and can include provider, work order, next due date, actions, downtime and comments.

// QR LABELS

Open an asset and select Generate QR. The QR contains the AssetScope asset identity and a compact set of basic equipment information. Download the QR label and place it on the physical equipment.

// DATA ONBOARDING

Use Transform with AI in the top bar to open Data Onboarding. The prompts help convert existing lists and maintenance histories into the master workbook without copying every row manually.

// ONLINE DATABASE

The workbook is a staging source. For multi-user operation, create related ASSET and MAINTENANCE tables. Asset_ID is the stable business key.

// MOVING ONLINE

Use Central Excel for a controlled starter, Dataverse for a governed multi-user MVP, or SQL plus an API for automated ingestion. Export the migration package only after readiness checks pass.
