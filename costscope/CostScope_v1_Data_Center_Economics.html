// QUICK START

Complete BUDGETS, COSTS and CAPACITY, then import the workbook. Use ALLOCATION_RULES and TARGETS when needed.

// BUDGET, FORECAST, COMMITTED AND ACTUAL

Budget is the approved envelope. Forecast is the current expectation. Committed is ordered or contractually committed. Actual is invoiced or booked cost.

// CAPEX AND OPEX

Use CAPEX for investment and OPEX for recurring operation. CostScope supports planning and operational analysis, not statutory accounting.

// PREVENTIVE AND CORRECTIVE MAINTENANCE

Maintenance remains a simple Cost Entry. Use PREVENTIVE_MAINTENANCE or CORRECTIVE_MAINTENANCE and reference the detailed record kept in AssetScope, Service Center or supplier documentation.

// CONTINGENCY RESERVE

Contingency is a planning buffer for unexpected costs. It is not Actual cost until a real Cost Entry is recorded. Register the reserve under CONTINGENCY and record consumed costs under their real category.

// SCOPE

Use only FACILITIES, RACKS, CABLING, SECURITY or GENERAL. FACILITIES covers electrical, UPS, generators, cooling and other building infrastructure.

// COST PER RACK UNIT

Cost per Installed U divides the selected annual cost by Installed U. Cost per Occupied U divides by Occupied U. Always compare values using the same cost basis.

// MONTHLY AND ANNUAL REPORTING

Annual values are sums of source amounts, not averages of monthly costs.

// MOVING ONLINE

Use Central Excel for a controlled starter, Dataverse for a governed multi-user MVP or SQL plus an API for automated ingestion.

// DATAVERSE IMPLEMENTATION

Create SITE, BUDGET, COST_ENTRY, CAPACITY_SNAPSHOT, ALLOCATION_RULE and TARGET. Use business IDs as alternate keys and controlled forms for data entry.

// SQL AND API IMPLEMENTATION

Add IMPORT_BATCH and VALIDATION_ISSUE for traceability. Expose controlled endpoints for costs, capacity, unit economics and reports.

// MONTHLY OPERATING MODEL

Update capacity, load costs, validate references, close the period, publish reports and retain evidence.

// BACKUP AND AUDITABILITY

Do not use browser storage as the production source of truth. Retain source exports, migration batches and monthly report extracts.
